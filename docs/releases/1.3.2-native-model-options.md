# 1.3.2：恢复原生智能体团队协作

|---|---|---|---|---|
| 版本说明 | 1.3.2 | DSH Desktop | 2026-11-23 | 现行 |

[← 文档索引](../README.md)

## 用法

在聊天栏打开「主模型」，模型列表下方有「启用智能体团队协作」开关。点旁边的 ⓘ 可查看原生说明。开关作用于当前会话，停用时沿用 DSH 的确认流程。模型和思考强度仍通过「应用」保存。

按 Apple HIG 的菜单分组与就地反馈原则，团队协作和模型编辑之间留有分隔线。ⓘ 的说明显示在菜单上方。启用后，开关状态即时更新，失败时在开关附近显示错误。

## 实现

DSH 把团队协作开关注册在原生模型菜单的 `conversation.input.model.options` 子插槽中。插件替换 `conversation.input.model` 时，通过宿主插槽清单嵌回原生组件，并传递会话投影、锁定状态、关闭回调和错误回调。宿主未提供该子插槽时，主模型菜单继续可用。

主模型菜单放在原生说明浮层之下，保留菜单原有的定位、关闭和焦点返回方式。

## 验证

- 185 项单元测试通过。覆盖原生选项接入、缺少原生选项时的降级以及主模型与其他模型菜单的层级隔离。宿主和客户端类型检查与构建通过。
- macOS 上的 DSH Desktop 实机验收覆盖开启团队协作、停用确认、ⓘ 显示说明、Escape 关闭和焦点返回。选中模型草稿再取消后，当前模型保持原样。
- 隔离原生宿主的初始、`resume`、`historical` 三阶段共 15 个用例通过，接缝报告为空，付费请求为 0。[已验证版本](../verified-versions.md#022-rc5通过)
